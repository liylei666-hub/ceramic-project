# BLOCKING CONSTRAINTS — Read Before Anything Else

> These constraints were discovered through actual experiment failures. A
> resuming agent must acknowledge each one before training, selecting, or
> deploying a model.

- [ ] **57-bit provenance is mandatory:** old 40-bit replay images were once
  paired with unrelated 57-bit labels. Only the hash-verified 57-bit replay
  manifest may be used, and training must fail closed on protocol, identifier,
  payload, coverage, and file hash.
- [ ] **Blind data must remain blind:** `blind_test10` must not be reused for
  training, tuning, interpolation, or candidate selection.
- [ ] **No-regression deployment gate:** any loss in real18, perspective,
  rotation, perspective-rotation, boards, or negative controls rejects the
  candidate. An in-training score or one recovered failure never authorizes
  deployment.

**Do not proceed with model work until all three boxes are acknowledged.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|----------------------|
| Payload-label mismatch | 40-bit encoded images silently received 57-bit targets in the old replay path. | blocking | Validate the 57-bit manifest, payload, identifier, coverage, and SHA-256 before loading any replay image. |
| Blind-set selection leakage | Repeated use of supplied failures or blind images can make apparent improvements non-generalizable. | blocking | Keep blind_test10 sealed and require newly printed/fired independent data for another selection cycle. |
| Partial-gate promotion | Several candidates improved an internal metric or one failure but regressed hard rotations. | blocking | Run the complete locator5 regression for every candidate and reject any single regression. |
