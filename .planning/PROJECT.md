## What This Is

这是一个面向真实陶瓷生产与手机拍摄/裁切流程的 57-bit 业务标识恢复系统。微信小程序负责按可见引导框裁出并上传 512×512 PNG，受保护的 ECS 解码 API 在回环地址上完成候选搜索、BCH-5 纠错、CRC-4 校验和 17 位业务标识解析；当前临时访问链路为 `Mini Program -> Cloudflare -> operator PC -> SSH -> ECS loopback`。

当前部署是已接受的运行基线，不等于已证明普遍泛化。适配集 01–18 的 18/18 仅证明当前两张实拍来源上的稳定性；项目下一步以独立的新制陶瓷、新实拍和生产手机裁切链路做盲测，再考虑合规 HTTPS 生产入口。

## Core Value

在真实陶瓷/生产手机裁切流程中精确恢复并通过 BCH-5 + CRC-4 校验的 57-bit 业务标识，同时保留负样本拒绝；泛化只以独立新实拍盲测结果表述，绝不把当前适配集 18/18 外推为普遍 100%。
